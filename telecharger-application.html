Comment installer SAMA-PACK ?

Sur Android

  1. Ouvrez sama-pack.store dans Chrome.
  2. Appuyez sur le menu ⋮ du navigateur.
  3. Choisissez « Installer l’application » ou « Ajouter à l’écran d’accueil ».
  4. Confirmez l’installation.

Sur iPhone

  1. Ouvrez sama-pack.store dans Safari.
  2. Appuyez sur le bouton Partager.
  3. Choisissez « Sur l’écran d’accueil ».
  4. Appuyez sur « Ajouter ».

SAMA-PACK est une application Web progressive (PWA). Elle utilise le site officiel et ses services existants. Une connexion Internet reste nécessaire pour actualiser les prix, les stocks et les commandes.

À savoir

Faut-il télécharger un fichier ou passer par un store ?

Non. L’installation se fait directement depuis le navigateur. Aucun APK ni téléchargement depuis un store n’est nécessaire.

Est-ce que mes commandes restent synchronisées ?

Oui. La PWA utilise le même compte client et les mêmes commandes que le site SAMA-PACK.

Les notifications fonctionnent-elles ?

Les notifications Web dépendent du navigateur, de l’appareil et des autorisations que vous accordez. Activez-les depuis votre compte lorsque l’option est disponible.
