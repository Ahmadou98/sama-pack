Comment installer SAMA-PACK ?

Sur Android

  1. Téléchargez le fichier APK depuis cette page officielle.
  2. Ouvrez le fichier depuis les notifications ou le dossier Téléchargements.
  3. Si Android le demande, autorisez temporairement votre navigateur à installer cette application.
  4. Appuyez sur « Installer », puis ouvrez SAMA-PACK.

Sur iPhone

  1. Ouvrez sama-pack.store dans Safari.
  2. Appuyez sur le bouton Partager.
  3. Choisissez « Sur l’écran d’accueil ».
  4. Validez avec « Ajouter ».

Sécurité : téléchargez toujours l’application Android depuis le domaine officiel sama-pack.store. La boutique a besoin d’une connexion Internet pour actualiser les prix, les disponibilités et vos commandes. L’installation ne nécessite aucun compte SAMA-PACK.

À savoir

Pourquoi Android affiche-t-il une autorisation avant l’installation ?

Un APK téléchargé depuis un site Web est installé hors du Play Store. Android peut donc demander d’autoriser le navigateur utilisé à installer des applications. N’accordez cette autorisation que pour un fichier provenant de notre domaine officiel.

L’application Android est-elle différente du site ?

Elle donne accès à la même boutique dans une fenêtre d’application dédiée. Le catalogue, les comptes, le panier et les commandes restent synchronisés avec SAMA-PACK.

Est-ce que je peux commander sans Internet ?

Non. Une connexion Internet est nécessaire pour vérifier les informations à jour et transmettre une commande. Aucune commande n’est validée hors connexion.
